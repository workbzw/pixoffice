# PixOffice Brand Assets

The selected brand identity is Zhou Li's front-facing mascot head.

- `logo.png`: transparent head symbol, used for application and browser icons.
- `title.png`: transparent mascot and PixOffice wordmark, used for brand titles.

These are the stable filenames for application integrations. The `v3` files
retain the original selected exports. Earlier versions are design explorations.
Do not derive brand assets from live character animation frames.

Generation prompts and identity notes are stored in
`art/branding/pixoffice-v3/README.md`.
