# 人物换装与定制复盘

本页记录公务制服定制中可复用的做法、失败方式和验收清单。下次新增职业服装、替换人物外观或修复动作时，先读本页，再按[素材准入流程](./character-admission.md)执行。尺寸与字段以[尺寸标准](./character-art-standard.md)和[资源包规范](./character-packs.md)为准，本页不另建一套发布规则。

## 本次成果与边界

已完成六人保留脸、发型和身份的制服换装，形成独立公务场景预览；外观与 `classic`、`members` 页面布局可以组合。横向步态、统一体积、坐姿语义和工作帧经历了多轮修复，源图与导入记录可重建当前画面。

**这不是“全部动作已通过正式验收”的案例。** 当前公务包仍是 `preview-only`：坐起过渡存在配准与轮廓连续性告警，赵审工作帧仍有手指区域外像素变化。技术尺寸通过、能够运行、用户认可某个动作，均不能替代完整质量审计和版本绑定的视觉验收。保留这些失败报告，不能把它们当成下一套素材的合格样板。

## 正确的制作顺序

### 1. 锁定保留项与变更项

先列清楚人物身份、脸、发型、配饰、镜头、比例、动作清单、工位和业务 ID 中哪些不变。换衣服默认只改变服装，不顺带更换人物身份、业务职责、工位、布局或运行时缩放。

为每个人保存自己正面、右侧、背面的站姿母版及哈希。参考图分工明确：本人母版提供身份，认可的动作图提供姿势，服装图提供衣服。不能让动作参照人物的脸或头部尺寸混进目标人物。

### 2. 先验证代表人物，再批量制作

整套换装先固定新服装三视图，再制作完整动作。单动作修复则继续使用已有母版，不重新生成无关动作。

先用一个代表人物验证完整流程；长发、眼镜或特殊轮廓有风险时，提前增加对应样本。不要六个人全部生成后才发现步态模板有误。已认可的动作冻结，后续只修改指定人物、方向或缺陷，可用像素哈希保护未改素材。

### 3. 使用实际动作参考，逐相位验收

“自然走路、摆臂、小步走”等提示词不够，需提供实际认可的完整动作帧，并在生成时明确四个相位。

| 横向相位 | 检查重点 |
| --- | --- |
| A 接触 | 近侧脚向前，近侧手臂向后，步幅克制 |
| B 经过 | 一条腿支撑，另一条腿从身体下方经过；手臂经过中立位置 |
| C 反向接触 | 支撑与迈步关系相反，近侧手臂向前 |
| D 反向经过 | 与 B 相反的腿支撑，脚收回髋部附近，接回 A 自然 |

重点检查左右脚真的交替、手臂与腿反向配合、支撑脚落地、头肩稳定，以及 `D → A` 和 `站立 → 行走 → 停下`。经过帧不是站姿；站姿也不能直接替代经过帧。远侧手自然遮挡可以接受，不要为强行露出双手把每帧都画成大幅摆臂。

本次周理、刘市参照王明的动作，陈书、赵审参照李研；参照只提供肢体姿势，不提供身份和尺寸。这是本次适合的分组，不是“所有男性/女性必须套同一模板”的通用规则。四张图不同、手部颜色数量正确，都不能证明步态正确。

### 4. 坐姿按真实椅子验证

本场景不在人物图里画椅子，人物必须以髋膝弯曲、脚部自然落下的姿势与真实椅面组合；离开椅子单看可能类似半蹲，但不能变成膝盖着地、脚折在身下的跪姿。

坐下后变矮来自身体折叠，不是整个人物或头部缩小。逐帧检查坐姿、前倾、起身中段与站立，并检查 `坐姿 → 工作` 和坐着转头时的头部、肩宽、臀部及脚底。只比较站立和坐姿两张端点图会漏掉中间跳变。

### 5. 工作帧保持身体像素稳定

当前轻微办公模板只允许手指小区域变化。应以同一个中性完整人物帧做局部图像编辑，输出仍为完整人物图片；头发、头、衣服和躯干不能每帧重画。不要剪贴其他人的手臂，也不要用运行时抖动遮掩差异。

生成结果若无法保留区域外像素，就继续保留为未验收候选，不能因“看起来像在打字”而放行。确实需要全身大幅工作动作时，应先定义与测试新的动作模板，不伪装为现有轻微办公模板。

### 6. 配准整个人物，不能逐帧凑数

先在同一场景显示尺度下确定每个人自己的母版比例，再导入动作。使用真实原图裁切框、人工头部区域、足底和嘴型挂点；长发、衣领、袖子和抬起的手不能混入头部测量。

同一动作所有帧共用等比导入倍率，包含坐起动作复用的端点帧；工作帧还应共用平移。头部面积用于选择和验证统一倍率，不是逐帧独立缩放的理由。统一倍率下仍不合格，应修原图或错误标注。

本次陈书、赵审的体积调整及横向动作微调均为特定源图的配准结果，不是下次可复制的固定系数。嘴型坐标随裁切、缩放、平移同步变换。禁止按全身包围盒凑相同高度、单独拉伸宽高，或在运行时按姿态改变 scale。

## 不正确的做法

| 做法 | 为什么不行 | 正确处理 |
| --- | --- | --- |
| 只写“自然行走”，不提供动作图 | 容易出现立正走路、双手后摆、步幅过大 | 锁定已认可的动作相位和参考帧 |
| 一次批量重画全部人物、全部动作 | 同时引入身份、比例和动作漂移，难以定位 | 代表人物先验收，局部修复已知缺陷 |
| 用站姿充当经过帧 | 像停顿或滑行，缺少真实换脚 | 生成独立经过姿态并检查末首循环 |
| 把坐姿统一拉到站姿高度 | 头部和肩宽变大，坐起时体积跳变 | 固定人物母版比例，身体自然折叠 |
| 只看头宽或自动测出“人脸” | 长发和衣服干扰，数值可能正确但视觉错误 | 人工头部标注，结合面积、宽高和并排画面 |
| 每帧独立缩放头或身体 | 静态单张合格，连续播放仍跳变 | 动作共用整图倍率，修复源图 |
| 每张打字帧重新生成整个人物 | 头发、衣服和身体重绘漂移 | 仅在允许区域内编辑，区域外逐像素验证 |
| 拼接手臂、补矩形色块遮缝 | 产生撕裂与边界，不是完整动作修复 | 用图像编辑生成一致的完整帧 |
| 调播放帧率、移动速度或桌椅位置遮缺陷 | 混入运行时变化，动作本身仍错误 | 素材问题在源图和导入阶段修复 |
| 自动测试通过就称全部完成 | 测试无法证明解剖、表情和动作自然 | 技术、动作质量、真实场景三层验收 |
| 放宽公差、修改旧白名单或伪填验收 | 把缺陷藏起来，下次重复踩坑 | 保留失败报告，明确预览与正式状态 |
| 直接编辑生成图集或删除所有原图 | 无法稳定重建，下一次构建丢失修改 | 修改版本化源素材，清理前做全新构建 |

## 下次定制验收清单

| 层级 | 必查内容 |
| --- | --- |
| 身份与服装 | 各人物自己的脸、发型、配饰、头身比例、三视图服装细节保持一致 |
| 静态技术 | 透明边缘、画布、人物自己的头部与足底、嘴型挂点、动作覆盖、图集可构建 |
| 步态 | 四相位、交替支撑、反向摆臂、小步幅、末首循环、转向及走停衔接 |
| 坐起 | 非跪姿、头部不缩放、每个中间帧连续、椅面与脚底位置正确 |
| 工作与说话 | 工作身体固定、手指在键盘位置、嘴型对齐、闭嘴行走、交谈后恢复 |
| 真实页面 | 正常速度、真实工位、拜访与中断恢复、重跑、资源重载；验证所需页面布局组合 |
| 发布 | 项目审计通过，人工视觉证据绑定本次素材版本，重新构建后可复现 |

自动检查先执行 `characters:draft` / `characters:audit`，隔离预览使用 `characters:preview`，视觉记录使用 `characters:review`，正式发布使用 `characters:publish`。完整参数和门槛只维护在[准入流程](./character-admission.md)中。技能附带的只读尺寸检查是补充，不替代项目质量审计。

同一缺陷连续两次定向生成仍未修好，先展示候选与剩余问题，再决定是否继续；不能无限重试或悄悄降低标准。任意图片、帧顺序、时长或配准规则变化，都必须重新验收对应版本。

## 源素材与交付记录

每次保留选中的原图、精确提示词、参考图角色、生成结果标识、原图哈希、裁切及配准记录、当前质量报告和必要的对比动图。旧候选只在确认不再被导入器读取、用户同意清理、且从保留源图全新构建成功后删除；不把临时缓存当成唯一源素材。

当前公务制作记录位于 [制作目录说明](../art/characters/police-uniform-v1/README.md)、[生成记录](../art/characters/police-uniform-v1/provenance.json)、[横向动作配准](../art/characters/police-uniform-v1/sidewalk-v13.json)和[质量报告](../art/characters/police-uniform-v1/qa/seating-v10-audit.json)。生成的 `public/civic-assets/` 不手工编辑，不提交 Git，也不传入 Docker 构建上下文；源图和导入配置必须保留。

人物外观、场景内容和页面布局分别维护。头像复用同一套人物资源，不另外生成一套不一致的脸；换装不改变业务 actor ID。交付时分别说明“生成可用”“技术检查通过”“动作质量通过”“真实页面验收通过”，不要以一个“成功”掩盖未完成项。
