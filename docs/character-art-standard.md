# 人物素材尺寸标准 v2

六个现有人物已有尺寸标注，但尺寸通过不代表动作已通过视觉验收。各自的正、侧、背站姿是尺寸母版；不能把王明的尺寸直接套给其他人物。新增或修改素材以[人物准入流程](./character-admission.md)为准，以下历史制作记录不能代替准入。

## 固定的不是图片外框，而是人物比例

| 项目 | 标准 |
| --- | --- |
| 单帧透明画布 | 256 × 384 px |
| 场景落脚基准 | (128, 344) |
| 站立参考高度 | 280 px |
| 场景显示高度参数 | 84，所有姿态共用 84 / 280 倍率 |
| 头部可见面积 | 对应人物、视角母版的 ±3.5% |
| 头宽与头高 | 辅助检查轮廓；默认头宽 ±14 px、头高 ±16 px |
| 头部横向中心 | x = 128，允许 ±2 px |
| 落脚误差 | 各姿态标注值 ±2 px |

头部面积、宽高取人工标注头部区域内 alpha ≥ 128 的像素，包含头发，不是人脸识别算法。v1 只匹配头宽，仍可能出现头高和整体面积偏小；v2 按可见面积等比配准，宽高作为额外约束。长发角色前倾和起身时发梢展开，这两帧允许宽度 ±24 px，面积检查不放宽。标注错误仍会导致视觉错误，所以数值校验不能替代人工验收。

坐下时身体折叠、整体高度变矮，但头部不能随整个人物一起缩小。导入只允许等比缩放整张人物；不允许为填满画布而单独拉伸宽高、按每帧全身高度适配，或运行时随姿态改变 scale。头形、颅顶到下颌比例、肩宽和服装仍需人工并排验收，单个头宽数字不能证明美术完全一致。

座位使用已有场景坐标语义：坐姿脚底 y=377、前倾 y=371、起身中段 y=354、站立和行走 y=344。它们不是不同渲染缩放；座位锚点与地面锚点不同。新增家具或坐姿应显式标注，不应偷偷移动整个角色补偿。

## 制作流程

1. 为一个人物保存正面、侧面、背面母版，固定外形、镜头、服装、光照和头身比例。
2. 带着母版生成动作。每张图明确格子顺序、左右迈腿和姿态；可见脸不画嘴，沿用独立嘴型层。
3. 人工检查头形和动作语义。生成提示不能保证像素级一致，不合格动作不能直接导入。
4. 在原图标注裁切框、头部区域、足底与嘴型锚点。始终从生成原图重新导入，不要反复缩放上一版 PNG。
5. 按对应视角的头部可见面积选定导入倍率，同一动作共用倍率，工作帧共用平移参数。配准后仍不合格应重做原图，不能逐帧缩放凑数；嘴型挂点同步变换。
6. 在正式包以外的暂存目录构建与审计。每个启用动作都要有尺寸规则和质量模板，工作帧必须保证手指区域外像素固定。
7. 在隔离人物预览和真实办公室中检查正侧背切换、左右脚交替、走停、坐起、桌面接触与独立嘴型，填写版本绑定的视觉验收后发布。具体命令见准入流程。

## 工程边界

- `character.json`：运行时动作、时长和嘴型挂点。
- `standard.json`：正式新素材必需的制作期尺寸验收规则，不打入运行时 manifest，不增加渲染开销。
- `quality.json` 与 `review.json`：动作质量规则及人工视觉验收，缺失则不允许正式发布。
- `scripts/characters/standard.mjs`：通用制作期校验，由现有 atlas 构建调用。
- `art/characters/office-motion-v2/registration.json`：六人站姿、坐姿与新正背面步态的头部区域标注。
- `art/characters/office-motion-v2/source-manifests/`：导入前固定的资源配置，重复导入不会累积缩放误差。
- `scripts/characters/register-office-motion.mjs`：历史原图导入算法，直接写正式素材的入口已停用。日常打包不重新生成或注册图片。

历史尺寸记录覆盖六人的站立、走路、坐下、起身、坐姿转头、背面打字及说话复用的身体帧。现在新包要求覆盖所有启用的身体动作；不准备继续使用的历史动作可从候选配置中移除。底层打包器仍兼容无尺寸规则的测试包，但正式发布、开发启动与生产构建不放行此类新包。

正、背面室内行走各有四张独立图：一侧接触、经过、另一侧接触、经过。手臂放低、小幅摆动，不再用站姿代替经过帧。预览每帧 200ms；办公室按实际移动距离推进步相（完整左右步周期为显示高度参数的 0.72 倍），遇阻不原地踏步。新增动作应先制作带方向、姿态、锚点、关键帧顺序的动作模板，再让各人物套用；仅有提示词不能保证一致性。

背面打字模板见 [坐姿敲键盘动作 v2](../art/characters/office-typing-v2/README.md)。前臂、手腕交替抬落，抬手 210ms、按键 110ms，四帧共 640ms。每人四帧采用同一制作期倍率，避免抬起的手进入头部标注带而引起缩放跳变。沿用各自背面头部母版与坐姿脚底 y=377；不通过晃动整个人物或桌椅模拟打字。v1 原图与动作保留。

## 历史记录

六人目前使用完整工作帧：四张 256×384 透明 PNG，四阶段每帧 250ms，按键阶段重复 3 秒，随后静止 1 秒。王明为[办公坐姿 v2](../art/characters/marvis-quiet-work-v2/README.md)，其他五人为[整图工作帧 v4](../art/characters/office-quiet-work-v4/README.md)。v4 存在身体重绘漂移，不能视为合格范本。新准入检查会拦截这些差异；本轮不重画旧图。所有旧 `--publish` 路径已禁用。

旧桌面适配试验见[电脑办公 v1](../art/characters/office-computer-work-v1/README.md)，采用无臂身体与独立手臂，不再作为新增人物的制作方案。新增人物沿用完整图片帧，不要求拆手臂。家具接触点仍可用于验收坐姿与手指位置。

旧导入器保留来源与算法记录，不用它们覆盖正式包。项目准入识别 `part.*` 为部件，不要求部件拥有头部；身体动作不能借此绕过尺寸与动作检查。原制作 Skill 的检查可作补充，但必须以本仓库准入命令为发布依据。

```sh
npm run characters:build
npm run characters:check
npm test
```

旧原图、`standard-v2/` 和动作帧保留。后续修复必须从暂存包开始，经新流程发布，不能重新运行旧版注册或嘴型制作入口。
