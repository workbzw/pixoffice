# 调度办公室

入口：`/dispatch/`。首页场景列表提供独立入口，原 `/office/` 行为不变。

## 当前范围

- 复用格子办公室背景、人物、家具、会话、任务、审批和运行时。
- 默认成员布局，右上角环形按钮显示 `运行中办公室数/办公室总数`，例如 `2/7`。
- 总览从右上角圆环的小尺寸拉伸放大为选择页，关闭时反向缩回。
- 选择办公室后，所选缩略图从原位置放大至全屏；目标画面就绪后再淡入真实办公室，
  不先缩回圆环。减少动态效果偏好下直接切换，进入过程中可用 Esc 结束视觉过渡。
- 点击按钮打开全屏浅灰总览，按可用宽度排列为每行 4、3、2、1 个办公室。
- 每项使用圆角整页缩略图，下方只显示名称、状态和待确认提醒；点击进入对应办公室。
- 当前办公室使用灰色外框，新增入口为同尺寸的纯加号块。总览不展示搜索栏、
  成员头像、目标及动态详情；这些内容仍在进入办公室后查看。
- 运行提示基于办公室全部会话的任务状态，而不是当前人物动画或网络连接状态。
- 蓝色边缘轻微呼吸表示有运行中任务；等待确认、异常、空闲分别标记。
- 总览使用各办公室真实运行状态生成缩略页面，人物、动作、家具、白板、成员和任务均来自对应办公室。
  手机端缩略图保持宽幅全景，进入办公室后使用正常的手机布局。
- 可见缩略图最多每秒刷新 2 次，离开可见区域、关闭总览或浏览器页面进入后台后停止采样。
  所有预览共用一个低分辨率 WebGL 渲染器，卡片只保存 2D 画面；不为每个办公室启动独立引擎或时钟。
  只暂停被遮挡主场景的展示，不停止后台办公室会话或任务推进。
- 进入办公室前，即使场景被总览遮挡，也先绘制包含人物、家具和白板的完整首帧，
  然后交接画面，避免从空房间突然跳到完整办公室。
- 预览只读访问已加载的办公室会话，不新增后端请求，不切换当前办公室，也不触发业务操作。
  预览尚未加载或加载失败时显示对应状态，不使用其他办公室的图片代替。

## 隔离边界

- 办公室目录与连接缓存：`pixoffice:dispatch:` 存储前缀。
- 地图：`browserPersistence` 的 `dispatch` 命名空间。
- 聊天：`dispatch:` 历史存储前缀。
- 本地布局偏好：`pixoffice:dispatch:page-shell:v1`。
- 新样式只由该入口加载，并限定在调度组件或 `.dispatch-office` 下。
- 外部接入仍使用现有办公室协议，不增加公共 layout ID 或新的执行控制命令。
  如果两个入口连接相同外部服务，服务端投递的数据仍是同一份，不会自动复制后端。

## 未提供的能力

本场景不执行模型或工具，不提供暂停外部任务、人工接管或恢复 Agent 的按钮。
“运行中”表示收到的任务状态，不承诺外部执行器此刻仍在线。
后续执行控制应先约定任务或会话级别的真实暂停、交接与恢复语义，再接入界面。
