# Studio V1 Artwork

本目录是独立 2.5D 办公室交互样板的源素材，使用内置 ImageGen 生成。参考用户提供的办公室设计图的空间构成与视觉气质，不把参考截图直接当作应用背景。

| 文件 | 用途 | 规格 |
| --- | --- | --- |
| `room.png` | 无人物、工位与白板的房间底图 | 1536 × 1024 |
| `stations.png` | 五个完整坐姿工位与一个空工位 | 3 × 2，单格 512 × 512，透明 |
| `portraits.png` | 对应五位员工的正面头像 | 3 × 2，单格 512 × 512，透明 |
| `board.png` | 第一版空白白板，保留源图供追溯 | 1448 × 1086，透明 |
| `board-v2.png` | 边缘清理后的白板，实际使用 | 1448 × 1086，透明 |
| `robot.png` | 巡回助手四个方向 | 2 × 2，单格 627 × 627，透明 |

工位与头像顺序：王明、李研、陈书 / 周理、刘市、空白。助手顺序：前左、前右 / 后左、后右。

准确提示词、生成文件 ID 和参考用途见 [`prompts.json`](prompts.json)。透明素材保留原始 alpha；预览图工具可能将低 alpha 的 RGB 内容显示得比浏览器更明显，验收以浏览器合成为准。

`build-public.mjs` 将源图编码为独立产品的 WebP 文件。没有修改现有角色包、现有动作图集或它们的验收标准。本批是视觉验证用素材，完整人物动画需另行制作并验收。
