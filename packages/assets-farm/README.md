# @pixoffice/assets-farm

Farm appearance IDs and semantic bindings for the frame animation adapter. Farm rules and renderer are not dependencies. `bindFarmFrames()` validates idle/walk in four directions and whole-body plant/water/harvest back-facing actions.

Build the independent asset distribution with `npm run assets:farm`. Sources and provenance live in `art/farm/`. Changing a future animation adapter does not change cultivation rules.
