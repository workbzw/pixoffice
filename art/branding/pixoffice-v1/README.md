# PixOffice Identity v1

Concept: a modular pixel P whose open counter suggests an office room or window.
Palette: coral `#DC6656`, ink `#2E3531`, white `#FFFFFF`.

The built-in imagegen tool was used for the initial concept. The selected
silhouette was recreated as clean vector paths for predictable small-size
rendering. Existing application branding has not been replaced.

Assets are under `public/brand/`:

- `pixoffice-symbol-v1.svg`: transparent primary symbol.
- `pixoffice-wordmark-v1.svg`: horizontal logo, live Helvetica Neue / Arial text.
- `pixoffice-app-icon-v1.svg`: coral application icon with a white symbol.
- `pixoffice-monochrome-v1.svg`: single-color symbol.

The wordmark uses live text; outline the lettering before sending it to a
print workflow that cannot guarantee font availability.

## Concept generation prompt

Use case: logo-brand. Create a production-quality original logo SYMBOL ONLY for the brand PixOffice, an approachable open-source AI office / human-AI team workspace with a clean bright white interface and miniature office characters. The core idea is a distinctive capital P constructed from a small precise modular pixel grid, with a generous rectangular negative-space counter suggesting an office room/window. Design one confident cohesive silhouette, restrained and geometric, subtly softened exterior corners while retaining the stepped pixel structure. It must read clearly as P and remain recognizable at 16px, not resemble a generic monitor icon. Use exactly one solid warm coral red (#DC6656) for the entire mark. Flat vector-like crisp logo graphic, no gradients, no lighting, no 3D, no shadows, no thin outlines, no textures, no extra disconnected decoration, no slogan, NO TEXT OR WORDMARK. Centered, balanced, generously spaced within a square canvas, single isolated symbol. True transparent background including negative spaces. Professional contemporary software identity with warmth and clarity. Avoid ornate pictograms, sparkles, generic AI brain/network symbols, tiny furniture details, badges or enclosing colored square backgrounds. Output one polished mark, not a contact sheet and not multiple options.
